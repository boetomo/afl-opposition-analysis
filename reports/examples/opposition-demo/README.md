# App demonstration archive

Real 2026 torpdata observations and cached predictions from the frozen tuned decoder-only Transformer, seed 2026. The sample includes the earliest available quarter in each club's earliest match and covers all 18 clubs. It was selected independently of model performance. These partial matches are a demonstration, not a recent-form analysis.

The manifest records source provenance, model fingerprint and file checksums. No model weights are required to use the app. See [app instructions](../../../docs/app.md).
